# Compatibility and source comparison

This comparison uses the current v2 tree and the formal Agent-run tree
`wqb_alpha_factory`. The formal tree was inspected read-only. Its
HEAD (`61e553d`) is the v2 merge base; v2 HEAD at comparison start was
`8c3b5ae`, 25 commits ahead and none behind. Both tracked trees were clean at
that point. The formal tree's ignored runtime state, configuration and
credentials were not read. The `new_ai` sample has no Git metadata, so its
`AIWorker/pyproject.toml` version (`1.0.0`), referenced files and project
structure are the available provenance; its `WebDataScope-1.7.3` directory is
a separate extension sample, not a BRAIN platform version.

production design. Evidence includes commit subjects and their tests/source

## Skills and reference integrity

The v2 project has exactly two skill directories under the root `skills/`:
`spc-prompt-writer` and `brain-evidence-review`. They have YAML frontmatter,
scoped descriptions and no secondary in-repository skill root. The new_ai sample
contains 18 worker skill directories plus an umbrella skill and SPC skill; its
internal Markdown links resolve in the supplied tree, but the skills reference
external-to-skill `workflow/`, `reference/`, `data/` and `memory/` artifacts
that are not present beside those skills in this sample. Their schemas and
platform assertions therefore cannot be treated as self-contained current
contracts.

## Unverified platform facts

No current authenticated BRAIN SPC form was available in this review. SPC
fields, character limits, model names, frequency values, weight bounds and the
`ISIN|MIC` sample contract remain **unverified**. The official public [BRAIN
competition page](https://platform.worldquantbrain.com/competition/) is a
general sign-in/competition landing page and does not expose those form details
to this review. Likewise, a platform-advertised Simulation type is not enough
to establish that this client's full write payload is supported; non-REGULAR
types remain rejected until the complete request schema is independently
verified and tested.
